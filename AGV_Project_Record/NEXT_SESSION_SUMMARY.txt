ESP32 디지털 트윈 AGV 다음 세션용 요약
작성일: 2026-08-04

[하드웨어]
- ESP32-WROOM-32E
- TB6612FNG
- WHEELTEC MG310P20 7.4V 엔코더 모터 2개
- 48mm 바퀴, 트레드 약 130mm
- 18650 보호회로 셀 2개, 2구 직렬 홀더
- ZX-052 V2.0 / LM2596 강압모듈, 출력 5.0V

[GPIO]
- AIN1=25, AIN2=26, PWMA=27
- STBY=13
- BIN1=33, BIN2=32, PWMB=14
- 왼쪽 엔코더 A=19, B=18
- 오른쪽 엔코더 A=17, B=16
- BOOT=GPIO0

[엔코더 선]
- 파랑 VCC=3V3
- 검정 GND=공통 GND
- 흰색=A
- 노란색=B

[모터선]
- 왼쪽 빨강 M+=AO1, 초록 M-=AO2
- 오른쪽 빨강 M+=BO1, 초록 M-=BO2

[전원]
- 배터리 +=LM2596 VIN+ 및 TB6612 VM 분기
- 배터리 -=LM2596 VIN- 및 TB6612 GND 분기
- LM2596 VOUT+ 5.0V=ESP32 5V
- LM2596 VOUT-=ESP32 GND
- ESP32 3V3=TB6612 VCC 및 양쪽 엔코더 VCC
- 모든 GND 공통

[업로드 절차]
1. 배터리 한 개 제거
2. 모든 화면과 LED가 꺼졌는지 확인
3. VOUT+→ESP32 5V 빨간선 분리
4. VIN+→TB6612 VM 빨간선 분리
5. USB 연결 후 업로드
6. USB 제거 및 ESP32 LED 꺼짐 확인
7. 두 빨간선 재연결
8. 배터리 삽입 후 시험

[확정값]
- 1회전=260 count
- 약 15cm=260 count
- 약 30cm=520 count
- 시계/반시계 제자리 90도=각 바퀴 176 count
- 352 count는 한쪽 모터선이 풀렸을 때 나온 잘못된 값이므로 사용 금지
- 고정 PWM 30%: 왼쪽 약 151RPM, 오른쪽 약 140RPM
- 목표 140RPM PID 시험 성공

[현재 완료]
- 양쪽 엔코더 정상
- 양쪽 모터 정상
- 배터리 독립전원 정상
- 직진 15cm/30cm 정상
- 시계 및 반시계 90도 정상
- 30cm→시계90도→30cm 자동 L자 경로 바닥 시험 성공

[최종 코드]
- AGV_Project_Record/final_l_route_main.cpp

[다음 목표]
1. 전원 분배단자, 퓨즈, 스위치, 기판 고정
2. 후진 검증
3. 엔코더 오도메트리 X/Y/방향각
4. ESP32 Wi-Fi 웹 조종
5. PC 디지털 트윈 연동

[안전 핵심]
- 배터리 원전압을 ESP32 5V/3V3에 직접 연결하지 않는다.
- 전원이 들어온 상태에서는 배선을 빼거나 나사를 조이지 않는다.
- USB와 LM2596 VOUT 5V를 ESP32에 동시에 공급하지 않는다.
- 임시 배선 상태에서는 사람 옆에서 짧게만 시험한다.
